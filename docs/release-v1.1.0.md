# VideoTrimmer v1.1.0

## 新增

- 支持一次导入多个视频
- 新增视频队列，可拖拽或使用上移/下移调整输出顺序
- 每个视频可单独预览、标记和添加多个截取区间
- 没有添加截取区间的视频会按完整内容输出
- 自动统一多个来源的分辨率、帧率和音频参数
- 无音频视频与带音频视频混合拼接时自动补静音
- 新增“静音导出”选项

## 改进

- 多视频编码统一使用单次 FFmpeg 滤镜图完成
- 输出进度按所有队列片段的实际时长计算
- 视频队列操作期间会锁定，避免修改正在导出的任务
- 继续支持 NVIDIA NVENC H.264 / H.265 和 CPU H.264
- 保持中、英、日三语界面与深色 / 浅色主题

## 输出说明

- 队列顺序就是最终视频的拼接顺序。
- 不同分辨率视频默认保持宽高比，并使用黑边补齐。
- 勾选“静音导出”后，输出文件不包含音轨。
